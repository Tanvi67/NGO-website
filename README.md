# NGO Website

This is a simple, responsive NGO website built using HTML, CSS, and JavaScript. The site provides information about the organization, its causes, volunteer opportunities, blog updates, and photo galleries. It is designed to work well on both desktop and mobile devices.

## Features

- Responsive layout with mobile-friendly navigation
- Dedicated pages for:
  - Home (`index.html`)
  - About (`about.html`)
  - Causes (`causes.html`)
  - Volunteer information (`volunteer.html`)
  - Blog (`blog.html`)
  - Gallery (`gallery.html`)
  - Contact (`contact.html`)
- Interactive elements using vanilla JavaScript (`script.js`)
  - Navigation menu toggling
  - Image carousel/gallery functionality
  - Simple form handling for contact or volunteer submissions
- Organized media assets stored in the `images/` folder

## Tech Stack

- HTML5
- CSS3 (including flexbox/grid for layout)
- JavaScript (ES6)

## Getting Started

1. Clone or download the repository to your local machine.
2. Open `index.html` in a web browser to view the site.
3. Modify HTML, CSS, or JavaScript files as needed for customization.

## Usage

The site is purely static and can be hosted on any static file server or service (GitHub Pages, Netlify, etc.).
